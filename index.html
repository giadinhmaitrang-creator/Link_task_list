Tạo dự án

Thêm link

Dùng tag để chia nhỏ hơn trong cùng một loại, ví dụ “hợp đồng”, “v2”.

Thêm nhiều link

Có thể ghi “Tiêu đề | URL”. Loại link được tự nhận diện, bạn sửa lại ở bảng bên dưới trước khi lưu.

Loại link

Mỗi loại có mã ngắn, màu và danh sách dấu hiệu nhận diện: một phần tên miền/đường dẫn (VD figma.com, docs.google.com/spreadsheets) hoặc đuôi file (VD .pdf). Link không khớp loại nào sẽ vào loại cuối cùng “Website”.

Google Calendar (Gmail cá nhân)

Lấy từ Google Cloud theo hướng dẫn bên dưới. Mã này không phải mật khẩu.
Hướng dẫn lấy Google Client ID (làm một lần, khoảng 15 phút)
  1. Mở console.cloud.google.com, đăng nhập bằng Gmail của bạn, tạo dự án mới (tên tùy ý, ví dụ “Kho Link”).
  2. Vào Google Calendar API → bấm Enable (Bật).
  3. Vào Google Auth Platform (màn hình xin quyền OAuth) → Get started: điền tên ứng dụng và email hỗ trợ; ở Audience chọn External. Sau đó ở mục Audience → Test users, thêm Gmail của bạn.
  4. Vào Clients → Create client → loại Web application. Ở Authorized JavaScript origins thêm đúng địa chỉ: → Create.
  5. Sao chép Client ID (dạng …apps.googleusercontent.com), dán vào ô trên, bấm Kết nối Google Calendar. Khi Google báo “ứng dụng chưa được xác minh”, bấm Tiếp tục (đây là ứng dụng của chính bạn), rồi cho phép xem lịch.

Outlook công ty (file .ics)

Cách xuất file .ics từ Outlook
  1. Outlook trên máy tính Windows: mở Lịch → File → Save Calendar (Lưu lịch) → More Options: Date Range chọn khoảng ngày (ví dụ 3 tháng tới), Detail chọn Full details → OK → Lưu file .ics.
  2. Outlook trên web / New Outlook không có nút xuất trực tiếp. Có thể dùng Cài đặt → Lịch → Lịch được chia sẻ → Xuất bản lịch để lấy link .ics rồi mở link đó để tải file, nếu IT cho phép.
  3. Quay lại đây, bấm Chọn file .ics…. Mỗi lần lịch thay đổi, xuất và nhập lại; lịch Outlook cũ trong web sẽ được thay bằng file mới.

Lịch chỉ được lưu trong trình duyệt này, không nằm trong file “Xuất dữ liệu” và không đưa lên GitHub. Lịch công ty có thể chứa thông tin nội bộ, hãy tuân thủ quy định bảo mật của công ty.
